## Wozu die Karte dient

Eine Aufgabe ist die kleinste Einheit der Arbeit: ein Titel, eine Beschreibung in Markdown, ein Status — und darunter das Gespräch dazu.

## Zuordnen

Eine Aufgabe kann an **Themen**, **Kontakten**, **Wissenseinträgen** und **Quellen** hängen. In jedem dieser Felder tippst Du, um zu suchen. Findet die Suche bei den Kontakten niemanden, legst Du die Person oder Organisation gleich dort an.

Über die Themen regelt sich auch, **wer die Aufgabe sieht**: Sie ist für alle sichtbar, die das Thema sehen dürfen. Eine Aufgabe ohne Thema sieht nur, wer sie angelegt hat.

## Antworten

Unter der Beschreibung steht der Verlauf. Eine Antwort ist erst für andere sichtbar, wenn Du sie veröffentlichst — bis dahin ist sie Dein Entwurf. Ist ein Agent zuständig, wird er durch eine veröffentlichte Antwort angestoßen.

## Die Karte im Stapel

:ui:karte_duplizieren: öffnet dieselbe Karte ein zweites Mal, :ui:karte_neu_laden: holt den aktuellen Stand, :ui:karte_schliessen: schließt sie. Ein Klick auf einen Verweis ersetzt alles rechts dieser Karte; mit gedrückter Umschalttaste fragt ein kleines Menü, wohin die neue Karte soll.
